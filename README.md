## 📝 About This Repository

- `Lecture-Notes/` holds lecture notes in the order of the lecture decks (`Lec01`, `Lec02`, and so on), and the units that had practice sessions also hold lab notes and example notebooks.
- `Coursework/` holds the explanations of the two paper assignments and a submitted report.
- Every lecture note, lab note, and assignment explanation comes as an English (`.md`) and Korean (`.ko.md`) pair.

> **🤖 AI Agent Usage**
> [Claude Code](https://claude.ai/download) was used to organize and translate the notes and to restructure the repository.

## 📚 Course Information

- **Semester:** Fall 2025 (September - December)
- **Affiliation:** Korea University Sejong

| Course&nbsp;Code| Course            | Type          | Instructor      | Department                              |
|:----------:|:------------------|:-------------:|:---------------:|:----------------------------------------|
|`DCCS403-00`|SOFTWARE APPLICATIONS|Major Elective|Prof. Heechan&nbsp;Chae|Department of Computer Science and Software Engineering|

### Course Overview

A course on the data processing techniques and deep learning models used across software application fields such as images, sound, and text, in which each theory lecture is followed by practice in applying them. The instructor, schedule, assessment, course policies, and progress are in the [course information document](Course-Information.md).
